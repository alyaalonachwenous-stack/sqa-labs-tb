# BPMN-моделі бізнес-процесів продукту «ЕдуПортал»

**Продукт:** П6 «ЕдуПортал» (`eduportal`)

**Спринт:** 1 («Продукт і вимоги»)

**Автор:** Учасник В (Інженер з тестування)

#### Інструмент моделювання та інструкція з відкриття файлів

- **Інструмент:** вебмоделер `bpmn.io` (`https://demo.bpmn.io`), стандарт нотації BPMN 2.0 (XML схема `http://www.omg.org/spec/BPMN/20100524/MODEL`).
- **Склад каталогу `docs/sprint1/bpmn/`:**
  1.  `01_quiz_attempt.bpmn` — вихідний файл моделі бізнес-процесу №3 «Проходження тесту» з повною графічною розміткою (`bpmndi:BPMNDiagram`).
  2.  `01_quiz_attempt.pdf` (або `.png`) — експортоване векторне/растрове зображення діаграми №1 для швидкого перегляду.
  3.  `02_course_creation.bpmn` — вихідний файл моделі бізнес-процесу №4 «Створення курсу» з повною графічною розміткою (`bpmndi:BPMNDiagram`).
  4.  `02_course_creation.pdf` (або `.png`) — експортоване зображення діаграми №2.
  5.  `review.md` — протокол перехресного рецензування обох моделей за чек-листом із 10 пунктів.
- **Як відкрити та експортувати моделі:**
  1.  Перейдіть на сайт `https://demo.bpmn.io`.
  2.  Натисніть кнопку **«Open File»** (іконка папки у лівому нижньому куті) та оберіть файл `01_quiz_attempt.bpmn` або `02_course_creation.bpmn`.
  3.  Для збереження у SVG натисніть **«Download SVG image»** у нижній панелі; для отримання PDF відкрийте завантажений `.svg` у браузері та оберіть `Ctrl+P` (`Cmd+P`) → **«Зберегти як PDF»** (орієнтація: Альбомна / Landscape).
