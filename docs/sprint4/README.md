## Команди швидкого запуску

* **Юніт-тести модуля (без браузера):** `mvn clean test`
* **Лише UI-тести (headless Chrome):** `mvn test "-Dgroups=ui" "-DexcludedGroups=none"`
* **UI-тести з видимим вікном браузера:** `mvn test "-Dgroups=ui" "-DexcludedGroups=none" "-Dui.headless=false"`
