## 1. Вступ

### 1.1 Призначення

Документ визначає вимоги до системи дистанційного навчання «ЕдуПортал» (далі — Система) версії 1.1 і є основою для аудиту вимог, проєктування тест-кейсів, автоматизації тестування та матриці простежуваності «вимоги × тест-кейси × дефекти». Читачі — тест-аналітики, інженери з тестування, керівник тестування, представник замовника.

### 1.2 Обсяг

«ЕдуПортал» — вебзастосунок класу LMS для закладу вищої освіти: курси з розділами й ресурсами, завдання зі здачею файлів або тексту, тести, форуми, журнал оцінок, самозарахування за кодовим словом, профіль, календар. Версія 1.1 охоплює функції поточної версії продукту (їх представляє демонстраційний застосунок, п. 2.2) та нову функцію «Журнал оцінок і рейтинг групи», бізнес-логіку якої винесено в модуль Java (розділ 5): зважений підсумок, шкала ECTS, штраф за запізнення, оцінювання тестів, умови зарахування. Рейтинг групи до обсягу версії 1.1 не входить.

### 1.3 Терміни і скорочення

| Термін | Означення |
| :-- | :-- |
| LMS (Learning Management System) | Система керування навчанням — вебзастосунок для навчальних матеріалів, контролю знань і обліку результатів. |
| Курс | Одиниця навчання: назва, коротка назва, категорія, дати, розділи з ресурсами та діяльностями, перелік учасників. |
| Діяльність (activity) | Інтерактивний елемент курсу: завдання (assignment), тест (quiz), форум (forum). |
| Самозарахування (self-enrolment) | Спосіб зарахування, за якого студент сам додає себе до курсу, увівши кодове слово. |
| Кодове слово (enrolment key) | Секретний рядок, який викладач задає для самозарахування на курс. |
| Елемент оцінювання (grade item) | Рядок журналу оцінок з максимальним балом і вагою у підсумку курсу. |
| Шкала ECTS | Літерна шкала A, B, C, D, E, Fx, F, у яку переводиться числовий підсумок курсу (BL-20). |
| Спроба (attempt) | Одне проходження тесту від кнопки «Спроба тесту» до надсилання відповідей. |

### 1.4 Посилання

1. Каталог продуктів пакета — картка продукту П6 «ЕдуПортал» (профіль, ролі, процеси, замовлення на функцію).
2. Шаблони артефактів пакета (реєстр дефектів вимог, тест-кейс, звіт про дефект, матриця простежуваності).
3. Демонстраційний застосунок поточної версії: https://sandbox.moodledemo.net.
4. Модуль бізнес-логіки: `code/modules/eduportal` (`README.md`, версії 1.0.0 та 2.0.0).

## 2. Загальний опис

### 2.1 Користувачі та ролі

| Роль | Хто це | Основні операції |
| :-- | :-- | :-- |
| Гість | Незареєстрований відвідувач | Перегляд переліку курсів без входу (F-30); вхід або гостьовий вхід (GUI-10). |
| Студент | Зарахований на курси користувач | Самозарахування (F-40), курс (F-50), завдання (F-60), тести (F-80), форуми (F-90), оцінки (F-100), профіль (F-110), календар (F-120). |
| Викладач | Веде курс | Наповнення курсу, налаштування самозарахування, оцінювання (F-70), звіт оцінювача (F-100), модерація форуму (F-90). |
| Менеджер курсів | Працівник навчального відділу | Створення курсів і категорій, призначення викладачів (F-130). |
| Адміністратор | Технічний адміністратор | Користувачі, методи зарахування, мовні пакети, параметри безпеки (S-10, S-20). |

### 2.2 Середовище

Система — вебзастосунок для Chrome або Firefox актуальної версії; мова інтерфейсу — українська. Поточну версію представляє демонстраційний застосунок [3]; тестові облікові записи `admin`, `manager`, `teacher`, `student` з паролем `sandbox24` (перевірено 08.09.2026). Модуль бізнес-логіки [4] — Java 17, Maven, без зовнішніх бібліотек; версія 1.0.0 відповідає поточній версії продукту, версія 2.0.0 — версії 2 для регресійного тестування.

### 2.3 Обмеження і припущення

- Демонстраційний застосунок скидається до початкового стану на початку кожної години: створені курси, діяльності, здані роботи зникають; тестові дані створюються заново перед кожним сеансом, тест-кейси — незалежні.
- Після скидання є два порожні курси («My first course», «My second course», викладач «Teacher Terri»). Завдання, тести, форуми та метод самозарахування з кодовим словом створює обліковий запис викладача або адміністратора перед виконанням тест-кейсів.
- Демонстраційний застосунок не надсилає електронну пошту: сценарії з листами (F-20, підтвердження адреси у F-110) перевіряються до моменту відправлення листа.
- Написи інтерфейсу наведено за українським мовним пакетом Системи. Специфікація описує продукт, а демонстраційний застосунок є лише його поточною версією, тому окремі написи і повідомлення в ньому можуть відрізнятися від наведених тут.
- Бали та відсотки у модулі — `double` з округленням HALF_UP; дати — `java.time.LocalDate` без часових поясів.

## 5. Вимоги до бізнес-логіки модуля

Бізнес-логіку функції «Журнал оцінок і рейтинг групи» винесено в модуль Java [4]: пакет `ua.kpi.tzyapz.eduportal`, три класи і чотири записи-DTO. Бали й відсотки — `double` з округленням HALF_UP (через `BigDecimal`), дати — `java.time.LocalDate`, порушення передумов методу — `IllegalArgumentException`. Сигнатури:

```java
GradeCalculator:
    double weightedTotal(List<GradeItem> items)
    String ectsLetter(double total)
    double latePenalty(double score, int daysLate)
QuizScorer:
    double questionScore(QuizQuestion question, Set<String> selected)
    double score(Map<String, Set<String>> answers, List<QuizQuestion> key)
EnrollmentValidator:
    boolean keyMatches(Course c, String key)
    boolean withinPeriod(Course c, LocalDate today)
    boolean hasCapacity(Course c)
    boolean prerequisiteMet(Student s, Course c)
    List<String> violations(Student s, Course c, LocalDate today, String key)
    boolean canEnroll(Student s, Course c, LocalDate today, String key)

record GradeItem(String name, double score, double weight)
record QuizQuestion(String id, Set<String> options, Set<String> correct)
record Student(String id, Map<String, Double> completedCourses)
record Course(String id, String enrolmentKey, LocalDate enrolStart, LocalDate enrolEnd,
              int capacity, int enrolled, String prerequisiteId)
```

| ID | Формулювання | Пріоритет |
| :-- | :-- | :-- |
| BL-10 | `GradeCalculator.weightedTotal(items)`: кожен елемент має бал 0..100 і вагу у відсотках; сума ваг усіх елементів дорівнює 100, інакше — виняток; бал поза 0..100, від'ємна вага або порожній перелік — також виняток. Підсумок = Σ (бал_i × вага_i) / 100, округлений до 2 знаків після коми (HALF_UP). | High |
| BL-20 | `GradeCalculator.ectsLetter(total)`: літера шкали ECTS за підсумком: **A: `total ≥ 95`; B: `85 ≤ total < 95`; C: `75 ≤ total < 85`; D: `65 ≤ total < 75`; E: `60 ≤ total < 65`; Fx: `35 ≤ total < 60`; F: `total < 35`.** Підсумок поза межами 0..100 — виняток. | High |
| BL-30 | `GradeCalculator.latePenalty(score, daysLate)`: −10 % від балу за кожен повний день запізнення, але не більше −50 % загалом; `daysLate = 0` — бал без змін; результат округлюється до 2 знаків (HALF_UP). Від'ємне `daysLate` або бал поза 0..100 — виняток. | High |
| BL-40 | `QuizScorer.questionScore(question, selected)` для питання з однією правильною відповіддю: 1 бал, якщо обрано саме правильний варіант і лише його, інакше 0. Питання без відповіді (порожня множина або `null`) — 0 балів. Обраний варіант, якого немає серед варіантів питання, — виняток. | High |
| BL-50 | `QuizScorer.questionScore(question, selected)` для питання з кількома правильними відповідями — частковий бал: (обрані правильні / усі правильні) − (обрані неправильні / усі неправильні), але не менше 0; якщо неправильних варіантів немає, друга частка дорівнює 0. Максимум — 1 бал. **Питання без відповіді (порожня множина або `null`) — 0 балів; обраний варіант, якого немає серед варіантів питання, — виняток (як у BL-40).** | High |
| BL-60 | `QuizScorer.score(answers, key)`: підсумок спроби у відсотках = (сума балів за питаннями / кількість питань у ключі) × 100, округлений до 1 знака після коми (HALF_UP). Кількість питань береться за ключем, а не за кількістю наданих відповідей. Порожній ключ — виняток. | High |
| BL-70 | `EnrollmentValidator.canEnroll(student, course, today, key)` повертає `true` лише коли одночасно: (1) кодове слово збігається з кодовим словом курсу точно, з урахуванням регістру; (2) `today` у межах періоду зарахування включно з датами початку і кінця; (3) є вільні місця — зарахованих менше за місткість (`capacity`); (4) передумовний курс, якщо заданий, складено з підсумком не менше 60 балів. Окремі умови — методи `keyMatches`, `withinPeriod`, `hasCapacity`, `prerequisiteMet`. | High |
| BL-80 | `EnrollmentValidator.violations(student, course, today, key)` повертає перелік порушених умов зарахування у зручному для користувача вигляді. | Medium |
